# Математическая постановка

## Источник

11 характеристик и семь факторов из текста задания; функции и коэффициенты из таблицы 1 на с. 6. Изображение системы (4) содержит иную 13-переменную редакцию. Она не смешивается с табличной без определения отсутствующих переменных. Код воспроизводит полную 11-переменную таблицу.

Две алгебраические части определены в `backend/defaults.py`. В принятой системе `dXi/dτ = (P_i - M_i)/S_i`; отсутствующие функции равны нулю. Коэффициенты, включая отрицательные, сохранены.

| i | P_i | M_i |
|---|---|---|
|1|`0.0186*X2*F1**0.8`|`0.01*X9*X10/(F3*F4)`|
|2|`0.085*X3*X7*X8*F1**0.8/F5`|`-0.95*X9*X10`|
|3|`-3.58e-6*F1**0.8*F3*F4/X1**2.9`|`0`|
|4|`0.9*X1`|`-0.0322*F1**0.8*F3*F4`|
|5|`0.0145*F2/X1**2.1`|`0`|
|6|`0.002*X2*F5*F6`|`-0.606*X4/(X10*X11*F7)`|
|7|`0.95*(X5+X6)**0.6*X10`|`0`|
|8|`0.817*X3`|`-0.42*X9*X10`|
|9|`1.4*(X3*X8)**0.2`|`0`|
|10|`0.052*sqrt(X3*F6)`|`0`|
|11|`375.1*X10*F7/F6`|`-0.0018/F5`|

Отдельных режимов обработки знаков нет. Термины P/M не предполагают неотрицательности, поэтому это алгебраические части, а не гарантированно положительные физические приток и отток.

## Шкалы и данные

Машинное время τ, X и F в готовых экспериментах безразмерны. Начальные уровни и S явно заданы как **допущения вычислительного примера**, не измеренные величины. Не заданы вещество, объект, единицы параметров и привязка к наблюдаемым потерям. S – положительный делитель производной, не скрытая конверсия индекса в людей или площадь.

Это исследование ОДУ, а не атмосферная модель переноса. Нет координат, концентрации, дозы, дисперсии, баланса массы облака, физической оценки границы опасности. Заявленные в задании 13% не воспроизводятся без исходного наблюдаемого ряда и не используются как результат нашей валидации.

## Численное решение

DOP853 по умолчанию, RK45 и Radau для сравнения. `rtol=1e-8`, `atol=1e-10`, `max_step=t_end/100`. Сетка вывода объединяет равномерные точки с точными четвертными моментами. Встроенный уточнённый эталон: DOP853 с `rtol=1e-11`, `atol=1e-13`, `max_step=t_end/1000`.

Не подставляется epsilon в знаменатели, не обрезаются отрицательные траектории. Для математически определённых, но физически недопустимых значений формируются предупреждения. Для нарушения области определения возвращается ошибка с указанием уравнения и времени. Промежуточные стадии интегратора также проверяются.

## Радар

`R_i = max(1e-9, max_j(abs(X_i(t_j))))`, `r_i = X_i/R_i`. Сравнение сценариев выводится на временных графиках и по исходным конечным значениям, а не наложением отдельно нормированных радаров. Масштаб один и тот же для четырёх срезов, а не заново для каждой четверти. Это максимум **по сетке вывода**, не гарантированный непрерывный экстремум. Площадь радара не считается общим риском.

## Верификация

Отдельная ручная арифметика проверяет все P/M в начальном состоянии. Аналитические эталоны: экспоненциальное затухание и циклически связанная линейная система против `scipy.linalg.expm`. Проверяются профили времени, все семь факторов, обе редактируемые части, включение четвертей, API и отказы на некорректных выражениях. Эмпирическая валидация требует внешних данных, которых в материалах нет.

## Редактирование зависимостей

Визуальный редактор работает с тем же выражением Pᵢ, Mᵢ или Fⱼ, которое получает
решатель. Поля внутри формулы задают `a*x**3+b*x**2+c*x+d`, где пользователь
выбирает x. Для внешнего фактора x всегда равен t. Тип зависимости определяется
старшим ненулевым коэффициентом: кубическая, квадратичная, линейная или постоянная.

Коэффициенты существующего выражения извлекаются из AST только тогда, когда
оно точно является полиномом степени не выше трёх от одного аргумента. Подгонки
нет. Многомерные выражения и дробные степени сохраняются. AST возвращает дерево
для математического отображения, а также диапазоны числовых литералов в UTF-16.
При вводе изменяются только эти литералы, без переписывания переменных и операций.
Дроби, скобки, знаки и показатели степеней сохраняют порядок исходного выражения.

Число полей зависит от формы: четыре у кубического полинома, три у квадратичного,
два у линейного, одно у постоянной. Остальные выражения показывают собственные
числовые литералы. Единственный сброс восстанавливает выбранную функцию текущего
сценария; при импорте это импортированная конфигурация.

Выбор другого вида полинома явно заменяет выбранную функцию целиком. При переходе
к ненулевой степени добавляется коэффициент 0.1 при старшей степени, если он был
нулевым. Свободный член подбирается так, чтобы сохранить значение при начальном
аргументе. Это начальная настройка вычислительного эксперимента, а не подгонка
по наблюдениям. Остальные уравнения сохраняются.

При запуске открывается кубический сценарий P₄=1.8·X₁³+0.0126. В начальном
состоянии X₁=0.7 получается 0.63, как у исходной P₄=0.9·X₁. Остальные 21 часть
уравнений и все семь факторов совпадают с таблицей. Коэффициенты новой связи
выбраны для исследования нелинейной формы и не приписываются заданию. Четыре
исходных сценария отчёта и их численные результаты не изменяются.

График исходной функции содержит 201 точку выбранного сечения. Остальные аргументы
фиксируются по начальному состоянию, факторы – при t=0. Неопределённые значения
остаются разрывами. Коэффициенты вычисляют кривую немедленно в том же порядке
слагаемых и с теми же ограничениями промежуточных значений, что и интерпретатор
Python. Нулевые слагаемые не включаются в выражение. Через 400 мс покоя
запускается то же Python-выражение в системе ОДУ.
Нативный API и WebAssembly используют общий `backend/preview.py`.

График функции f(x) показывает выбранную связь; временная траектория Xᵢ(t)
на вкладке результатов показывает решение всей системы. Это разные величины.
Нелинейность выбранной связи не гарантирует заметной кривизны временной
траектории на любом коротком интервале.

Проверки сопоставляют точки сечения с вычислением правых частей, сравнивают
кубический сценарий с независимым аналитическим решением и проверяют одинаковый
результат API и браузерного моста. В браузере отдельно проверяются незавершённый
ввод, смена коэффициентов, ползунки и отбрасывание устаревших ответов/ошибок.
